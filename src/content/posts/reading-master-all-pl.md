原文：[如何掌握所有的程序语言](https://www.yinwang.org/posts/master-pl)

## 核心观点

**语言 = 语言特性的组合**。就像电脑是 CPU、内存、显卡的组合一样，语言也只是变量、函数、类型系统、lambda、GC 等特性的组合。

## 关键论点

1. **通用特性可迁移**：变量、函数、循环、递归在所有语言中都存在，只是语法不同
2. **高手的学习方式**：带着问题找特性，像查字典一样，而不是抱着大部头手册
3. **合理的入门语言**：Scheme、C、Java、Python、JavaScript
4. **专注关键特性**：忽略 printf 格式化、省略花括号等次要语法
5. **终极进阶**：自己动手实现语言特性，从使用者变成创造者

## 我的体会

作为 Java 转 Python 的开发者，这篇文章说到了点子上：

- 我不需要"从零学 Python"，只需要知道 Java 里的概念在 Python 里怎么表达
- 真正需要学的"新特性"就那么几个（鸭子类型、装饰器、yield、async）
- 设计模式（策略模式、依赖注入）是跨语言的

## 值得记住的一句话

> 程序语言的设计者，不过是像 Dell、联想一样的"组装机"。语言特性的设计者，才是像 Intel、AMD 那样核心技术的创造者。
